# ScreenGuard Pro

This is an independent native Android project. Do not modify sibling projects.

For interface changes, use the installed UI UX Pro Max skill at `.agents/skills/ui-ux-pro-max/SKILL.md` and the reviewed design system at `design-system/screenguard-pro/MASTER.md`. The supplied design and explicit user requests take priority over generic search results. Fonts must be bundled locally with their licenses, and all Compose typography roles must be set. Preserve system text scaling and motion-duration scaling.

Keep update signing material out of git. Never silently accept a new APK signing certificate or use a debug key for production updates. Run unit tests, lint, build, and the device test workflow before claiming APK verification.
