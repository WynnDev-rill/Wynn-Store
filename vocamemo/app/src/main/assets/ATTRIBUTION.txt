PRIVACY: No account, analytics, advertising or cloud sync. Personal data stays in the app's private local Room database. Android backup is disabled; export/import JSON is explicit through the system file picker. Internet is used for GitHub update checks/downloads and external sources you open. TTS selects an installed English voice that does not require network. No vocabulary is sent to an AI service.
