# ArithMemo 1.0.0

Rilis pertama aplikasi hafalan aritmatika native Android.

- Ruang hafalan dalam daftar dan flashcard interaktif.
- Penjumlahan, pengurangan, perkalian, pembagian bulat; operand 1–3 digit.
- Latihan mengingat, tes 60 detik, soal acak, dan pengulangan terjadwal adaptif.
- Kelompok hafalan, pilihan operasi, target harian, statistik dan tema gelap.
- Penyimpanan lokal transaksional, pemulihan sesi dan ekspor/impor cadangan.
- Pemeriksaan update GitHub, notifikasi opsional dan instalasi APK terverifikasi.

Android 8.0 atau lebih baru. Tanpa akun, iklan, analitik, atau materi rumus.
