# Native visual review

Visual evidence is captured from real Android emulators, not browser mockups. Sources: GitHub Actions run 44077663917, API 26 normal home/flashcard/recall/settings/statistics and API 36 normal, dark with font scale 1.6, and landscape. Fresh final captures are checked again after the final gate.

The supplied references are reflected in the royal-blue daily card, pale-blue equation surfaces, generous rounded actions, Jakarta typography and restrained green learning/selection states. Flashcards prioritize one equation and a direct reveal action. Filters collapse to keep memorization visible. No unrelated decorative visual system or paid reference assets are included.

Source review confirms labelled Material navigation, number-key descriptions, spoken feedback live regions, 48dp minimum touch targets, theme roles, scalable sp typography, edge-to-edge insets, system Back, a rail at wider widths and scrollable long screens. WCAG color-token checks are recorded in VERIFICATION.md. Default Compose motion follows system duration scaling.

Findings corrected: periodic storage must not disable the keypad; the long settings navigation label wrapped poorly at large text and is now “Setelan”; night/font-change captures must wait for the app's loaded UI. Header/system bar icon contrast follows the app's selected light/dark theme.

The review does not claim physical-handset refresh-rate/haptic measurements or a manual TalkBack session. Emulators verify functional and layout breadth; semantics are inspected in native tests and source.
