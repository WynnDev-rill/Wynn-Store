# ArithMemo design system
Visual authority: supplied blue flashcard icon; Dribbble Math Learning 26974846 (royal blue, pale blue sections, pill actions), Learn Mode 24138576 (calm type, clear progress, green success), Behance Flashcards 111025041 (large tactile cards and restrained controls). Translate patterns into native Compose, do not copy paid UI assets.
Palette: primary #245BE8, ink #17243B, muted #52627A, canvas #F6F8FD, white surfaces, blue tint #EAF0FF, green #23764C, warm amber #916100, error #B3261E. Dark palette preserves contrast. Plus Jakarta Sans bundled with OFL, 16sp body, 28–32sp headings, 40–56sp scalable equations. System font scaling stays enabled.
24dp page inset, 16dp gaps, 24dp card corners, 56dp primary actions, minimum 48dp touch targets. Four labelled navigation destinations. Simple outlined Material icons. No emoji-as-icons. Cards communicate action by label, state by text and color. Motion: Compose crossfade and spring-sized transitions respecting system duration scale. No mandatory gestures. All long screens scroll; content max-width 720dp.
