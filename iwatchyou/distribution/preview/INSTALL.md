# IWatchYou Uji 1.0.3

APK ini berisi kandidat perbaikan deteksi aplikasi agar bubble mengikuti aplikasi yang sedang dipakai. Paketnya `id.wynn.iwatchyou.preview`, berbeda dari IWatchYou produksi.

1. Pasang APK IWatchYou-1.0.3-preview.apk. Versi lama tetap terpasang beserta riwayatnya; riwayat versi uji dimulai terpisah.
2. Di Aksesibilitas, matikan layanan IWatchYou lama lalu aktifkan **IWatchYou Uji · pemantauan waktu**.
3. Buka dua aplikasi bergantian. Bubble harus terlihat dan waktunya bertambah. Kembali ke Home atau kunci layar untuk memastikan timer aplikasi berhenti.

Jika Android memblokir pengaktifan Aksesibilitas untuk APK yang baru dipasang, buka Info aplikasi IWatchYou Uji → menu titik tiga → Izinkan setelan terbatas, lalu kembali ke Aksesibilitas. Nama menu dapat berbeda pada HyperOS.

Pembaruan otomatis produksi 1.0.2 tetap memerlukan kunci penandatangan produksi dari sesi sebelumnya. Versi uji ini memakai tanda tangan debug dan diperbarui manual dengan APK uji. Jangan menghapus versi produksi untuk mencoba APK ini.

Kode, audit dan AGENTS.md: https://github.com/WynnDev-rill/Wynn-Store/pull/25
Poco F6 dengan HyperOS 3.0.304.0 belum diuji langsung.
